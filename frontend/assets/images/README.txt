Place the Sree Consultancy logo here.

Steps:
1. Save the logo image you shared as "sree_logo.png"
2. Put it in this folder:  assets/images/sree_logo.png
3. Run: flutter pub get   (then hot restart / rebuild)

Until the file is added, the app shows a styled navy "Sree Consultancy"
text fallback in place of the logo — nothing breaks.
